# Nova Engine v83 - Autonomous Technical Lead

Nova Engine is an autonomous software engineering assistant equipped with CLI task tracking, Architecture Decision Record (ADR) logging, and automated version control integrations.

## Features
- Dual Interactive/CLI Modes: Run python main.py for direct conversation or pass arguments directly.
- Planner Intelligence: Automated task estimations, risk assessments, and intelligent priority justifications.
- Architecture Decision Records (ADRs): Track architectural trade-offs using structured decision records.
- Automated Version Control: Automatic Git commits and release note generation.

## Quick Start
`powershell
# Boot Interactive Mode
python main.py

# Direct CLI Execution
python main.py plan
python main.py next task
python main.py decision list
`
